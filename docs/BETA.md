# koreanpulse beta acquisition plan

Goal: **50 active beta users in 30 days**, then **measure conversion** to determine whether the audience-form-pricing fit is real.

If conversion is too low, this document doubles as the diagnostic for which lever (audience / form / price) to change.

## Audience reframe — crypto-native traders rotating into KOSPI/KOSDAQ

The original ICP was "Sarah, $500M long/short fund analyst". Real talk:
those people use Bloomberg, work through compliance, and their MCP-Desktop
adoption rate is low.

The **real audience showing up in 2026** is crypto-native retail/prosumer
traders rotating from on-chain into Korean equities. They:

- Already live in Discord / Telegram / Twitter, not in Salesforce
- Are AI-native — Claude Desktop, Cursor, Perplexity in their daily flow
- Care about real-time disclosures (DART = blockchain explorer for KOSPI)
- Have crypto-grade volatility tolerance and small-cap appetite (KOSDAQ)
- Pay in $20–200/mo range without procurement
- Hate sales calls
- Read English but tolerate Korean snippets / will copy-paste into AI

This shifts our acquisition channels (next section). Pricing focus:
**Cloud Solo $29/mo is the floor**, Cloud Analyst $79/mo is the real
revenue tier, Cloud Desk $249/mo serves boutique teams. OSS self-host
(AGPL, BYO keys, community support only) is a separate lane for hackers
— not a pricing tier. Enterprise / SLA is contact-us only.

## Measurement framework — 30-day cohort

Beta starts when ≥ 5 free signups exist. Cohort = first 50 free signups.

### Day 0 instrumentation

Server-side capture (already in `agentprod.CostTracker`):

- `signup_at` (when first license issued)
- `tool_calls` (per day, per tool)
- `tools_used` (which of 7 tools touched)
- `last_active_at`
- `referrer` (which channel — Smithery / HN / cold email / etc.)

Manual capture (Supabase row):

- email
- self-described role (analyst / journalist / dev / other) — single optional field at signup

### Day 7 milestone

A signup is **"engaged"** if they made ≥ 10 tool calls across ≥ 2 distinct days in week 1.

| Engaged % | Signal |
|---|---|
| > 50% | Strong product fit. Push paid prompt. |
| 25–50% | Average. Continue, refine onboarding. |
| < 25% | Onboarding broken or wrong audience. Diagnose. |

### Day 30 conversion

Day 31: send opt-in email asking which plan they'd choose. Two questions only:

> Q1. Would you pick Cloud Solo $29/mo, Cloud Analyst $79/mo, Cloud Desk $249/mo, or None?
>
> Q2. If "None" — what stopped you?

Keep it one-click for Q1 (mailto: links per option).

### Decision matrix (Day 31)

| Day-30 conversion (any Cloud tier) | Read | Action |
|---|---|---|
| **> 10%** | Strong | Lock pricing, scale acquisition channels that worked |
| **5–10%** | OK | Hold pricing, double down on top channel, cut others |
| **2–5%** | Weak | One-shot pivot: drop Cloud Solo $29 → $19 or Cloud Analyst $79 → $49, re-test 30d |
| **< 2%** | Audience or form mismatch | See *Pivot ladder* below |

### Pivot ladder (only if < 2% conversion AND > 50 signups)

In order:

1. **Audience pivot** — try Korean diaspora investors instead of foreign-fund analysts. Same product, new acquisition channels.
2. **Form pivot** — add a thin web app on top of MCP (most analysts don't use Claude Desktop). MCP becomes feature, not form.
3. **Use-case pivot** — same data, different buyer. Korea-entry SaaS teams instead of investors.
4. **Sunset** — if pivots 1–3 don't move the needle, accept the verdict and redirect time.
